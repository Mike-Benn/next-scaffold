
GETTING STARTED

1.  PROVIDE DATABASE_URL ENV VARIABLE

2.  PROVIDE BETTER_AUTH_SECRET ENV VARIABLE - CAN GENERATE HERE: better-auth.com/docs/installation

3.  PROVIDE BETTER_AUTH_URL ENV VARIABLE - BASE URL OF APP: http://localhost:3000

4.  RUN DB GENERATE AND DB MIGRATION TO GENERATE AUTH TABLES - pnpm run db:generate, pnpm run db:migrate
