
GETTING STARTED

RUN PNPM INSTALL

PROVIDE DATABASE_URL ENV VARIABLE

PROVIDE BETTER_AUTH_SECRET ENV VARIABLE - CAN GENERATE HERE: better-auth.com/docs/installation

PROVIDE BETTER_AUTH_URL ENV VARIABLE - BASE URL OF APP: http://localhost:3000

RUN DB GENERATE AND DB MIGRATION TO GENERATE AUTH TABLES - pnpm run db:generate, pnpm run db:migrate
